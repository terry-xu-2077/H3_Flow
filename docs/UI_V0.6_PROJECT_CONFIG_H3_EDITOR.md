# ShotMill V0.6 项目配置与 H3 提示词编辑规范

> 日期：2026-09-13  
> 状态：覆盖 V0.5 中对应的工作台顶部、项目配置、提示词编辑与结果预览规则。  
> 参考实现：`terry-xu-2077/ComfyUI-TerryXu-nodes` 中的 H3 提示词编辑器。

## 1. 项目工作台顶部

左侧固定为：

```text
[🏠] 返回首页
```

中间继续显示：

```text
[文件夹] 项目标题 ✎
```

右侧顺序：

```text
[项目配置]   表格 / 卡片
```

项目配置按钮必须显示图标 + “项目配置”文字，不使用纯图标按钮代替。

---

## 2. 任务工具栏

`＋ 新建任务 / N 个任务` 工具栏在表格视图和卡片视图中都必须存在。

卡片模式可以继续保留“新建任务卡”。

---

## 3. 右侧结果预览

右侧栏只读。

任务存在 Result 时：

- 显示结果缩略图；
- 点击缩略图打开独立播放弹窗；
- 播放弹窗使用真实 `videoUrl`；
- 不在右侧栏内展开播放器。

---

## 4. 用户提示词 / AI 增强提示词

任务编辑器包含两个独立维度：

```text
提示词来源： [用户] [AI 增强]
显示方式：   [可视化] [文本]
```

当前来源标签决定最终使用哪份提示词；两份文本独立保存。

用户和 AI 提示词各自记忆 `visual | text` 显示方式。

可视化模式和文本模式必须编辑同一份标准 H3 字符串，不允许维护两份互相漂移的内容。

---

## 5. H3 可视化编辑器

可视化模式参考 ComfyUI TerryXu H3 提示词编辑器，不新定义另一套语法。

第一阶段至少处理：

- H3 区块标题；
- Subject / Picture / Video / Audio；
- Shot；
- Speaker；
- Dialogue；
- 时间标签；
- scenetrans / cutoff；
- retention / reference；
- H3 Task 标签；
- 常用 Camera Command。

当素材引用可以解析到当前任务资产时，显示**资产名**，而不是原始文件名。

---

## 6. 项目配置窗口

项目配置当前只暴露两个一级分类：

```text
项目信息
资产管理
```

弹窗尺寸固定，切到资产管理时不得被资产数量撑大。资产列表必须在弹窗内部滚动。

### 6.1 项目信息

包含：

- 项目标题；
- 项目简介；
- “AI 增强时使用项目简介作为背景”开关。

项目简介是 AI Prompt Enhancer 的项目级背景，不自动拼进用户提示词。

---

## 7. 资产管理

资产管理采用：

```text
左侧：紧凑资产列表
右侧上方：预览
右侧下方：资产元数据 / 文件信息
```

图片和视频支持全屏预览；视频、音频使用对应播放器。

### 7.1 资产名与原始文件名必须分离

**资产名**：

- 用户可编辑；
- 左侧资产列表显示资产名；
- 任务提示词 `@` 菜单显示资产名；
- 改资产名不得重命名磁盘文件。

**原始文件名**：

- 只读；
- 只在右侧资产详细信息中显示；
- 不在左侧资产列表、`@` 菜单、普通创作界面暴露；
- 永远不因资产名修改而变化。

### 7.2 分类与标签

分类、标签有创作管理价值，因此如果出现在右侧详细信息中，必须是**可编辑元数据**，不能作为不可操作的只读信息堆在那里。

当前规则：

- 分类：分段按钮，角色 / 场景 / 道具 / 参考；
- 标签：可编辑文本，支持逗号 / 中文逗号分隔；
- 修改后立即更新左侧资产摘要；
- 保存后进入项目 Asset 数据。

### 7.3 只读文件信息

只读区只显示真正不可编辑的技术信息，例如：

- 格式；
- 媒体类型；
- 时长（如存在）；
- 原始文件名。

禁止把“分类 / 标签”同时做成只读字段和可编辑字段，造成重复。

### 7.4 删除资产

从项目移除资产时，同步清理任务中已经失效的 AssetBinding，避免悬空引用。
