# ShotMill V0.6 后端适配增量

> 日期：2026-09-13  
> 基于：`V0.5_BACKEND_FRONTEND_ADAPTER.md`

## 1. Project Read Model 增量

项目配置需要：

```ts
type ProjectSettingsView = {
  id: string;
  title: string;
  description: string;
  useDescriptionForAiPrompt: boolean;
};
```

首页 `ProjectSummary` 不必返回完整 description。

---

## 2. 项目配置写接口

推荐：

```http
PATCH /api/v1/projects/{projectId}
```

`useDescriptionForAiPrompt` 只决定 AI 增强上下文，不改变用户 Prompt 文本。

---

## 3. AI Prompt Enhancer 请求

项目简介由后端 Adapter / Prompt Service 组装：

```ts
type PromptEnhanceRequest = {
  projectId: string;
  taskId: string;
  userPrompt: string;
  projectBackground?: string;
  taskAssets: TaskAssetRef[];
  previousContext: PromptContextSummary;
};
```

只有项目明确启用且 description 非空时才提供 `projectBackground`。

---

## 4. TaskEditorView 增量

```ts
type TaskEditorView = {
  id: string;
  displayNumber: string;
  title: string;

  promptSource: "user" | "ai";
  userPrompt: string;
  aiEnhancedPrompt: string;

  editorPreference: {
    userViewMode: "visual" | "text";
    aiViewMode: "visual" | "text";
  };

  durationSeconds: number;
  previousTaskDurationSeconds: number | null;

  generation: {
    resolution: "720p" | "1080p" | "2K";
    quality: "快速" | "标准" | "高质量";
    mode: "全能参考" | "首尾帧";
    contextMode: "片段承接" | "尾帧承接" | "不承接";
    contextStartSeconds?: number;
    contextEndSeconds?: number;
    contextDurationSeconds?: number;
  };

  assetBindings: TaskAssetRef[];
};
```

`previousTaskDurationSeconds` 由 Adapter 按 Story Order 聚合，前端不应自行理解 Scene / Placement。

### 4.1 片段承接区间

片段承接不再只有“承接时长”，而是上一任务时间轴上的明确区间：

```text
contextStartSeconds >= 0
contextEndSeconds <= previousTaskDurationSeconds
contextEndSeconds > contextStartSeconds
contextDurationSeconds = contextEndSeconds - contextStartSeconds
```

新任务默认：

```text
end = previousTaskDurationSeconds
start = max(0, end - 1)
```

即默认承接上一任务末尾 1 秒。

旧数据只有 `contextDurationSeconds = N` 时：

```text
end = previousTaskDurationSeconds
start = max(0, end - N)
```

真实 Provider 如果只支持“尾部 N 秒”，Adapter 再把区间转换成 Provider 参数；Core / UI 仍保留明确区间语义。

---

## 5. Final Prompt 选择规则

```text
promptSource == user → finalPrompt = userPrompt
promptSource == ai   → finalPrompt = aiEnhancedPrompt
```

两份原始文本都必须保留。

---

## 6. H3 可视化 / 文本模式

后端始终只存标准 H3 字符串。

Rich HTML、contentEditable DOM、中文 Chip 文案都不入库。

---

## 7. 项目资产管理

推荐接口：

```http
GET    /api/v1/projects/{projectId}/assets
POST   /api/v1/projects/{projectId}/assets
PATCH  /api/v1/projects/{projectId}/assets/{assetId}
DELETE /api/v1/projects/{projectId}/assets/{assetId}
```

### 7.1 资产显示名与原始文件名

后端必须区分：

```ts
type ProjectAssetView = {
  id: string;
  name: string;             // 用户可编辑的资产名
  originalFileName: string; // 只读
  projectRelativePath: string;
  mediaType: "image" | "video" | "audio";
  category: "character" | "scene" | "prop" | "reference";
  tags: string[];
};
```

规则：

- 修改 `name` 不得重命名磁盘文件；
- `@` 菜单显示 `name`；
- `originalFileName` 只用于资产详情；
- 普通任务 UI 不暴露原始文件名。

### 7.2 分类与标签

分类、标签是可编辑元数据，不属于只读文件属性：

```http
PATCH /api/v1/projects/{projectId}/assets/{assetId}
```

可接受：

```json
{
  "name": "林澜雨夜主视觉",
  "category": "character",
  "tags": ["主角", "雨夜"]
}
```

格式、媒体类型、原始文件名、checksum 等技术字段由后端维护，不接受普通 UI 修改。

删除资产时检查 Task Binding，避免悬空引用。

---

## 8. Result 播放

TaskSummary 推荐增加：

```ts
primaryResult: null | {
  id: string;
  previewUrl: string | null;
  videoUrl: string;
}
```

右侧栏只消费摘要，不请求完整 Job 调试对象。

---

## 9. 兼容旧数据

旧项目缺少字段时：

```text
description = ""
useDescriptionForAiPrompt = false
promptSource = user
userViewMode = visual
aiViewMode = visual
contextMode: 自动承接 → 片段承接
```

旧 Context 只有时长时，Adapter 将其映射为上一任务末尾的等长区间。
