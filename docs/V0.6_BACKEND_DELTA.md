# ShotMill V0.6 后端适配增量

> 日期：2026-09-13  
> 基于：`V0.5_BACKEND_FRONTEND_ADAPTER.md`  
> 对应 UI：`UI_V0.6_PROJECT_CONFIG_H3_EDITOR.md`

## 1. Project Read Model 增量

V0.6 项目配置需要后端在项目级 Read Model 中增加：

```ts
type ProjectSettingsView = {
  id: string;
  title: string;
  description: string;
  useDescriptionForAiPrompt: boolean;
};
```

`ProjectWorkspaceView.project` 推荐扩展为：

```ts
project: {
  id: string;
  title: string;
  description: string;
  useDescriptionForAiPrompt: boolean;
}
```

首页 `ProjectSummary` 仍不必返回完整 description，避免列表接口携带无用大字段。

## 2. 项目配置写接口

推荐：

```http
PATCH /api/v1/projects/{projectId}
```

请求：

```json
{
  "title": "异星边境 第二版",
  "description": "项目级世界观、视觉基调与创作限制",
  "useDescriptionForAiPrompt": true
}
```

后端必须校验：

- title 非空；
- description 可空；
- `useDescriptionForAiPrompt` 仅决定 AI 增强上下文，不改变用户 Prompt 文本。

## 3. AI Prompt Enhancer 请求

Prompt Enhancer 不应让前端手工拼接项目简介。

推荐由 Frontend Adapter / Prompt Service 组装：

```ts
type PromptEnhanceRequest = {
  projectId: string;
  taskId: string;
  userPrompt: string;
  projectBackground?: string;
  taskAssets: TaskAssetRef[];
  previousContext: PromptContextSummary;
};
```

规则：

```text
project.useDescriptionForAiPrompt == true
AND project.description 非空
→ projectBackground = project.description

否则
→ 不发送 projectBackground
```

项目背景属于 **AI 上下文**，不是 Final Prompt 的可见前缀。

## 4. TaskEditorView 增量

V0.6 TaskEditorView 建议扩展：

```ts
type TaskEditorView = {
  id: string;
  displayNumber: string;
  title: string;

  promptSource: "user" | "ai";
  userPrompt: string;
  aiEnhancedPrompt: string;

  editorPreference: {
    userViewMode: "visual" | "text";
    aiViewMode: "visual" | "text";
  };

  durationSeconds: number;
  generation: {
    resolution: "720p" | "1080p" | "2K";
    quality: "快速" | "标准" | "高质量";
    mode: "全能参考" | "首尾帧";
    contextMode: "片段承接" | "尾帧承接" | "不承接";
    contextDurationSeconds?: number;
  };

  assetBindings: TaskAssetRef[];
};
```

### editorPreference 的归属

`userViewMode / aiViewMode` 只是编辑器显示偏好，不影响 Provider 输入。

可以：

1. 存任务 UI metadata；或
2. 存用户本地偏好。

当前前端 Mock 放在 generationParams 只是过渡实现。真实后端接入时建议从生成参数中拆出，避免 UI 偏好污染 Provider 参数快照。

## 5. Final Prompt 选择规则

提交任务时：

```text
promptSource == user
→ finalPrompt = userPrompt

promptSource == ai
→ finalPrompt = aiEnhancedPrompt
```

两份原始文本都要继续保存。

禁止“切 AI 标签后把 AI 文本复制覆盖 User Prompt”。

## 6. H3 可视化 / 文本模式

后端始终只存标准 H3 字符串。

```text
可视化模式 ─┐
             ├→ 同一个 raw H3 prompt string
文本模式   ──┘
```

可视化 Chip、中文标签、缩略图、camera command 中文名都属于前端表示层。

后端不要存：

- Rich HTML；
- contentEditable DOM；
- 中文 Chip 文案；
- 前端生成的可视化节点结构。

## 7. 项目资产管理

推荐接口：

```http
GET    /api/v1/projects/{projectId}/assets
POST   /api/v1/projects/{projectId}/assets
PATCH  /api/v1/projects/{projectId}/assets/{assetId}
DELETE /api/v1/projects/{projectId}/assets/{assetId}
```

`POST` 负责真实文件导入、项目相对路径、checksum、媒体元数据与预览图生成。

前端当前 `URL.createObjectURL()` 仅作为 Mock UI 预览，接真实后端后必须由后端返回稳定的 `previewUrl` / media URL。

删除资产时后端应检查 Task Binding：

- 未被引用 → 可直接删除；
- 已被任务引用 → 返回引用关系，由前端确认是否解除绑定后删除。

## 8. Result 播放

TaskSummary 建议增加：

```ts
primaryResult: null | {
  id: string;
  previewUrl: string | null;
  videoUrl: string;
}
```

右侧栏只消费 `previewUrl`。

用户点击后，播放弹窗消费 `videoUrl`。

不要让右侧栏为了播放去请求完整 Job / Result 调试对象。

## 9. 推荐实施顺序

```text
Project settings schema / PATCH
        ↓
Project asset CRUD
        ↓
TaskEditorView promptSource + contextDuration
        ↓
Prompt Enhancer projectBackground
        ↓
TaskSummary primaryResult
        ↓
SSE / runtime 保持 V0.5 方案
```

## 10. 兼容旧数据

旧项目缺少字段时：

```text
description = ""
useDescriptionForAiPrompt = false
promptSource = user
userViewMode = visual
aiViewMode = visual
contextMode: 自动承接 → 片段承接
```

迁移应由 Adapter 层兜底，不让 React 组件处理版本判断。
