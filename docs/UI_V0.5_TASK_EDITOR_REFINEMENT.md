# V0.5 任务编辑窗细化规范

> 日期：2026-09-13  
> 适用：Terry导演工作台任务编辑弹窗、通用下拉控件

## 1. 顶部标题区

任务编辑弹窗不再显示“编辑任务 · T01-001”这类操作型标题。

顶部固定表达“正在编辑哪个任务”，而不是“现在执行什么动作”：

```text
[任务图标] 任务名称 ✎
任务编号 T01-001
```

规则：

- 显示任务图标；
- 直接显示任务名称；
- 名称旁显示铅笔图标；
- 点击名称 / 铅笔后原位进入编辑状态；
- 任务编号为次要信息；
- 禁止重新出现“编辑任务”作为主标题。

## 2. 上下文承接

“上下文承接”禁止继续使用 Select / 下拉菜单。

固定使用三段式选项卡：

```text
[片段承接] [尾帧承接] [不承接]
```

### 2.1 片段承接

原“自动承接”统一改名为 **片段承接**。

片段承接允许在选项卡下方出现少量与当前模式直接相关的参数，当前至少包含：

- 承接时长（秒）。

语义：从上一任务末尾取得指定时长的画面 / 运动连续性信息，交给后端 Context Adapter 转换成当前生成 Provider 所需的上下文输入。

后续如 Provider 支持更多可控项，只能在该模式被选中时按需出现，禁止一次性把所有 Context 参数平铺出来。

### 2.2 尾帧承接

只使用上一任务最终帧作为当前任务的起始视觉参考。无必要参数时不显示空表单。

### 2.3 不承接

当前任务独立生成，不引用上一任务的连续性上下文。

## 3. 提示词标签 = 当前使用的提示词

“用户 / AI 增强”不是单纯的预览标签，也不再需要“采用增强结果”按钮。

**当前选中的标签就是当前任务要使用的提示词来源：**

```text
[用户]      → 使用用户提示词
[AI 增强]   → 使用 AI 增强提示词
```

切换标签后立即切换“当前使用”的提示词来源，但两份文本本身保持独立，不互相覆盖。

保存时：

- 当前为“用户” → `finalPrompt = userPrompt`；
- 当前为“AI 增强” → `finalPrompt = aiPrompt`；
- 同时保存 `promptSource = user | ai`，以便重新打开任务时恢复上次使用的标签；
- 用户提示词与 AI 提示词分别保留，切换来源不得导致另一份文本丢失。

## 4. 两层底栏

提示词内容区底部固定保留素材引用提示：

```text
@ 输入 @ 引用当前任务资产
```

该栏在“用户 / AI 增强”之间切换时位置、尺寸、内容都不变化。

整个弹窗最底部是操作栏：

```text
当前使用：用户提示词                      [取消] [保存]
```

切换到 AI 增强后变为：

```text
已使用AI增强提示词                       [取消] [保存]
```

禁止再出现“采用增强结果”按钮，因为标签切换本身已经承担提示词来源选择。

## 5. 下拉菜单宽度

全应用 `PortalSelect` 必须遵守：

> **菜单宽度 = 触发控件宽度。**

禁止根据选项文本、`scrollWidth` 或父容器宽度自动扩张。

同时继续支持：

- 空间不足时向上展开；
- 通过 Portal 避免父容器裁切；
- 菜单不得超出视口；
- 长文本在菜单内部截断 / 省略，不得撑宽浮层。

该规则适用于分辨率、质量、生成模式以及后续所有使用 `PortalSelect` 的界面。

## 6. 弹窗尺寸

桌面端任务编辑是高频核心编辑器，应使用接近工作区宽度的大型浮窗：

- 最大宽度约 1480px；
- 左侧任务配置约占 20%–22%；
- 右侧提示词区占主要面积；
- 小屏幕再响应式收窄 / 单列。

仍需遵守“左侧只放少量高频生成控制，右侧以内容编辑为主”的原则。
