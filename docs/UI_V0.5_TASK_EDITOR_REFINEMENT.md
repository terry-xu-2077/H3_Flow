# 任务编辑窗细化规范

> 最新更新：2026-09-13  
> 适用：Terry导演工作台任务编辑弹窗。最新规则覆盖旧 V0.5 中的尺寸与控件描述。

## 1. 顶部标题区

任务编辑弹窗顶部固定表达“正在编辑哪个任务”，不显示“编辑任务”字样：

```text
[任务图标] 任务名称 ✎
任务编号 T01-001
```

任务名称可原位修改；任务编号只读。

---

## 2. 弹窗尺寸

任务编辑器不再使用接近全屏的 1480px 大窗。

桌面端目标：

- 最大宽度约 `1180px`；
- 左侧任务配置约 `280px`；
- 右侧仍保留主要提示词编辑空间；
- 小屏幕响应式收窄，必要时单列。

原则：内容区仍是主角，但不能为了提示词区域把整个弹窗无限放宽。

---

## 3. 生成参数控件

减少下拉菜单，常用且候选固定的参数优先直接可见。

### 3.1 分辨率

使用标签 / 分段选择：

```text
[720P] [1080P] [2K]
```

### 3.2 质量

使用标签 / 分段选择：

```text
[快速] [标准] [高质量]
```

### 3.3 总秒数

使用单值滑块，不使用数字输入框。

- 最小 1 秒；
- 当前值始终可见；
- Provider 的真实上限后续由 Capability / Profile 决定，UI 不把模型限制硬编码进 Core。

### 3.4 生成模式

使用标签 / 分段选择：

```text
[全能参考] [首尾帧]
```

固定少量选项禁止再使用下拉菜单。

---

## 4. 上下文承接

上下文模式继续使用三段式标签页：

```text
[片段承接] [尾帧承接] [不承接]
```

### 4.1 片段承接

“承接时长数字框”废弃，改为**上一任务时间轴上的双端区间选择器**。

规则：

- 时间轴总长度 = 上一个任务的实际时长；
- 步长 = 1 秒；
- 新任务默认选择上一任务最右侧 1 秒；
- 左右两端都可拖动；
- 选中区间同时决定：
  - `contextStartSeconds`；
  - `contextEndSeconds`；
  - `contextDurationSeconds = end - start`；
- 旧数据只有 `contextDurationSeconds` 时，迁移为“上一任务末尾 N 秒”；
- 如果当前任务前没有上一任务，显示“无可承接片段”，不伪造时间轴。

### 4.2 尾帧承接

只使用上一任务最终帧作为当前任务的起始视觉参考，无额外参数时不显示空表单。

### 4.3 不承接

当前任务独立生成，不引用上一任务连续性上下文。

---

## 5. 提示词来源与显示模式

提示词来源：

```text
[用户] [AI 增强]
```

当前选中的标签就是真正使用的 Prompt Source：

- 用户 → `finalPrompt = userPrompt`；
- AI 增强 → `finalPrompt = aiPrompt`。

两份提示词独立保存。

每一份提示词又分别支持：

```text
[可视化] [文本]
```

`可视化 / 文本` 只是同一份标准 H3 字符串的两种编辑视图，不产生第二份内容。

---

## 6. 两层底栏

提示词内容区底部固定：

```text
@ 输入 @ 引用当前任务资产
```

整个弹窗底部：

```text
当前使用：用户提示词 / 已使用AI增强提示词        [取消] [保存]
```

禁止重新引入“采用增强结果”按钮。

---

## 7. 下拉菜单

只有确实存在大量或动态候选项时才使用 `PortalSelect`。

所有 `PortalSelect` 仍必须满足：

> 菜单宽度 = 触发控件宽度

固定少量候选项应优先使用标签 / 分段选择，而不是下拉菜单。
