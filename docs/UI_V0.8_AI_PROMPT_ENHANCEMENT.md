# V0.8 AI 提示词增强与历史版本 UI 规范

> 日期：2026-09-13  
> 状态：覆盖此前任务编辑窗中“AI 增强只是第二个文本区”的旧表现。

## 1. 核心心智

任务编辑器里始终有两套独立提示词：

```text
[用户] [AI 增强]
```

当前选中的标签就是当前任务保存 / 生成时采用的 Prompt Source。

- 用户 → 使用用户提示词；
- AI 增强 → 使用当前选中的 AI 增强版本。

AI 增强不得覆盖用户提示词。

---

## 2. AI 增强页顶部

只有切到 `AI 增强` 标签时，才显示：

```text
[AI提示词增强记录 ▼]
```

规则：

- 用户标签不显示历史菜单；
- 没有增强记录时显示“暂无增强记录”，并禁用下拉；
- 每次增强完成都会追加一个新版本；
- 最新生成版本自动被选中；
- 用户可切换回任意历史版本；
- 旧项目只有单一 `aiPrompt` 时，迁移为一条 legacy 记录。

建议历史项文案：

```text
增强记录 1 · 14:32
增强记录 2 · 14:35
最新版本 · 14:41
```

---

## 3. AI 增强空状态

尚未生成过 AI 提示词时，AI 内容区显示：

```text
AI增强的提示词显示在这里
点击右下角“增强”，基于用户提示词生成一个新的增强版本。
```

不要用空白黑框让用户猜下一步。

当 AI 标签被选中但尚无提示词时，底部保存按钮应禁用，避免把空 Prompt 保存成当前使用版本。

---

## 4. “增强”按钮

AI 内容区右下角固定显示：

```text
✨ 增强
```

规则：

- 只在 AI 增强页显示；
- 可重复点击；
- 每次点击都创建一个新的增强版本；
- 生成期间显示“增强中…”并暂时禁用按钮；
- 用户提示词为空时禁用增强；
- 增强失败时在内容区附近显示轻量错误，不弹第二个复杂窗口。

“增强”不是一次性确认按钮，不再使用“采用增强结果”。

---

## 5. AI 增强上下文

AI 增强请求的主要输入顺序：

```text
当前用户提示词
  + 上一任务摘要文本
  + 项目简介（仅用户启用时）
  + 当前任务资产摘要 / 引用
  + 当前任务少量生成参数
```

### 5.1 上一任务上下文

**默认只发送摘要型文本。**

推荐字段：

```text
previousTaskSummary
```

来源优先级：

1. 上一任务 `summary`；
2. 若为空，使用简短 `userIntent`；
3. 再为空，退化为任务标题。

禁止默认发送：

- 上一任务完整用户 Prompt；
- 上一任务完整 AI Prompt；
- 上一任务完整 Result 描述；
- 内部 ContextLink / Job / Provider 调试对象。

这样可以保留叙事与镜头连续性，同时避免上一任务的完整细节污染当前提示词增强。

### 5.2 项目背景

只有项目配置中明确开启：

```text
AI 增强时使用项目简介作为背景
```

才把 `projectBackground` 发送给增强服务。

项目简介不会直接拼进用户提示词。

---

## 6. 历史版本与编辑

AI 历史版本至少保存：

```ts
type AiPromptHistoryItem = {
  id: string;
  createdAt: string;
  prompt: string;
  sourceUserPrompt: string;
  previousTaskSummary?: string;
  projectBackgroundUsed?: boolean;
};
```

当前 UI 允许用户在选中的 AI 版本上继续手工编辑；保存时使用当前编辑后的文本。

重新点击“增强”仍以**当前用户提示词**为主要输入，而不是自动以旧 AI 版本继续递归增强。

如果未来需要“基于当前 AI 版本继续增强”，应作为独立能力设计，不混入当前按钮语义。

---

## 7. 底部状态

用户标签：

```text
当前使用：用户提示词
```

AI 标签且已有内容：

```text
已使用AI增强提示词
```

AI 标签但尚未生成：

```text
当前使用：AI增强提示词（尚未生成）
```

保存行为：

```text
promptSource == user → finalPrompt = userPrompt
promptSource == ai   → finalPrompt = 当前 AI 版本文本
```

---

## 8. 可视化 / 文本模式

用户与 AI 两边继续分别支持：

```text
[可视化] [文本]
```

历史版本切换只替换标准 H3 字符串；可视化模式仍只是该字符串的富编辑表现。
